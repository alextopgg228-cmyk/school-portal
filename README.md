# School Portal for GitHub Pages

Это статическая версия школьного сайта для GitHub Pages.

На GitHub Pages нет Node.js сервера и прямого MS SQL подключения, поэтому здесь опубликована безопасная статическая копия данных из школьной БД.

## Быстрый запуск локально

Откройте `index.html` в браузере или загрузите эту папку в GitHub репозиторий.

## Публикация

1. Создайте новый public repository на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /root.
6. Откройте ссылку вида `https://USER.github.io/REPO/`.
